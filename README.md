# Code-Editor-Web-App

Web-Browser-Based-Code-Editor — a lightweight, browser-based code editor built with HTML, CSS, and JavaScript.

## Features
- Edit HTML, CSS, and JavaScript files in the browser
- Live preview of your code
- Simple, responsive UI
- No backend required — runs entirely in the browser

## Tech stack
- JavaScript
- HTML
- CSS

## Getting started

To run locally (static site):
1. Clone the repo:
   git clone https://github.com/thepratikgupta/Code-Editor-Web-App.git
2. Open `index.html` in your browser, or serve the folder with a simple static server:
   - Python 3:
     python -m http.server 8000
     then open http://localhost:8000
   - Node (http-server):
     npx http-server .

## Usage
- Type or paste code into the editor panels.
- Use the live preview pane to see the rendered output (HTML/CSS/JS) in real time.
